# 🤖 AI 照片尺寸测量工具

上传照片 → AI 自动识别手和物体 → 一键计算实际尺寸

## ✨ 功能特性

- 🤖 **全自动 AI 分析** — 无需手动标定点，AI 自动检测
- 🖐️ **MediaPipe 手部检测** — 自动识别手部位置，计算中指长度
- 📦 **COCO-SSD 物体检测** — 自动识别风扇、手机、书本等 80+ 种物体
- 📐 **自动比例尺计算** — 根据手掌尺寸自动换算像素到实际尺寸
- ✏️ **手动微调** — AI 结果不满意？可以手动调整物体边界
- 🔒 **纯前端运行** — 照片不上传服务器，保护隐私
## 🌐 在线体验

👉 **[AI 自动检测版](https://huangyan920.github.io/photo-measure)**

上传照片即可自动识别手和物体，直接给出尺寸结果。
## 🚀 部署方式

### Vercel Drop（最快，2分钟）

1. 解压 zip 文件
2. 访问 [vercel.com/drop](https://vercel.com/drop)
3. 把文件夹拖进去，自动获得网址

### 本地预览

需要启动本地服务器（因为 AI 模型加载需要 HTTP/HTTPS）：

```bash
# 用 Python
python -m http.server 8080

# 或用 Node.js
npx serve .

# 然后浏览器打开 http://localhost:8080
```

⚠️ **不能直接双击打开 HTML 文件**，浏览器安全策略会阻止模型加载。

## 📖 使用流程

1. **设置参照物参数**（底部面板）
   - 选择年龄段、性别
   - 或输入自己的精确中指长度（精度最高）

2. **上传照片**
   - 确保手和物体在同一平面上
   - 尽量正面平拍

3. **等待 AI 分析**（约 5-15 秒首次加载模型）

4. **查看结果**
   - AI 自动框出检测到的手和物体
   - 自动计算物体宽度和高度

5. **手动微调（可选）**
   - 点击「手动微调」
   - 在物体四角点击 4 个点
   - 重新计算尺寸

## ⚠️ 精度说明

| 方案 | 预期精度 | 说明 |
|------|---------|------|
| 自定义精确中指长度 | ±10~15% | 推荐，用尺子量自己的手 |
| 年龄段平均值 | ±15~25% | 个体差异较大 |
| 手动微调 | ±5~10% | 最精确，但需要操作 |

## 🛠️ 技术栈

- TensorFlow.js — COCO-SSD 物体检测
- MediaPipe Hands — 手部关键点检测
- 纯前端 HTML/CSS/JS，无后端
